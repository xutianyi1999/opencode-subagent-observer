## 已知限制

- 真实宿主仅返回持久日志同步序号，未返回正文；changes 明确标记并附当前投影快照。
- 未结束的文字/推理片段不在纯 pull 可读范围内。
- 真实模型联调覆盖正常执行；授权等待、错误与取消的查询由可控传输测试覆盖，不声称全部 provider 场景均已模型联调。
- 每页最多 100 条消息，单次正文预算最多 40000 字符；可翻历史页，并按消息继续读取。
- 细节文本有预算限制，概览中保留所选条目及工具身份与状态；不承诺任意大小结果能一次返回。
- 不保证跨接口原子快照，结果包含查询时间范围。
- 不对未测试的宿主作全面兼容保证，也不通过精确版本门禁拒绝它们。
